VOIDSTORM — Neon Arena Defense is an original twin-stick arena shooter that runs in the
browser. You pilot the last interceptor in a 1280×720 neon arena against escalating waves
of five drone kinds — chasers, sine-weaving weavers, splitters that burst into minis, and
shooters that keep their distance and fire plasma orbs. Kills chain a combo multiplier up
to ×3.0; drones drop Rapid Fire, Shield, Bomb and +Hull pickups; every fifth wave is a
surge. Sound is fully synthesised with WebAudio — no audio files — and the simulation is
fixed-timestep and seeded, so every run is deterministic.

Controls: WASD or arrow keys to fly, mouse to aim, click or Space to fire, Shift to dash,
P to pause, M to mute.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. (`node main.ts` builds the make.fun entry —
the game plus its dossier — into an output directory.)
